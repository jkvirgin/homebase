# Remember

Key facts and preferences live in one short file, `~/Homebase/memory/facts.md`, on the reader's own computer. It is read at the start of every chat, so keep it short and current.

## The folder

- Use `~/Homebase/memory/`. Do not put it in Documents, Desktop or iCloud Drive; those often sync to iCloud.
- If it does not exist, create `facts.md` and `history.md` from the templates below and tell the reader in one line where they are.
- Never write memory anywhere else, and never put any of it in a web search or in a repository.

## facts.md

```
# What to remember

## About me

## Preferences

## People

## Other facts
```

Each fact is one line starting with `- `, in plain words, with the date it was added: `- Not a developer; explain plainly and give exact steps. (added 2026-11-26)`.

## Saving

1. Save only what the reader asked you to keep, or a lasting preference they stated clearly. When you notice something worth keeping that they did not ask you to save, ask once: "Should I remember that …?"
2. Put it under the right heading. If it changes an existing line, replace that line instead of adding a second one.
3. Confirm in one line: what you saved, in their words.

## Showing

"What do you remember about me": read `facts.md` back grouped by heading, in plain words. Mention that they can open the file themselves in any text editor.

## Changing or forgetting

Find the line, show it, and remove or change it. Confirm in one line. If more than one line matches, ask which.

## Never save

- Passwords, PINs, account or card numbers, Social Security or other ID numbers. Say plainly that these do not belong in memory.
- Anything from the journal. The journal stays separate. In a journal chat, do not offer to remember anything.
- Guesses about the reader. Only what they said.

## Privacy, in plain words (say once, the first time)

The file stays on this computer. Because it is read at the start of every chat, its contents are sent to Anthropic with each chat, like anything else typed to Claude. Keep anything you would not type to Claude out of it.
